## LinkedIn / Reddit (EN)
AI made building apps cheap. What's scarce now is trust: no ads, no data selling, no subscriptions that lock you in.

So I started **Unsubscribed!** (https://unsubscribed.dev): useful open-source apps on a simple deal. If an app costs us nothing to run, it's free forever. If it does (servers, AI), we run it at cost plus a small fee shown up front. And you can always take the code and run it yourself.

The first one I'm opening up is **Controlled**: one remote on your phone for your LG TV and your Windows PC (a Bluetooth keyboard and trackpad, nothing to install on the PC). Code: https://github.com/unsubscribed-co/controlled

It's in a closed test on Google Play, and I'm looking for 12 people to try it for 14 days: https://groups.google.com/g/controlled-testers
